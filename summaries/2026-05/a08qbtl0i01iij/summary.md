### Shrnutí support ticketu

1. **Téma ticketu:**
   - Uživatel požaduje vygenerování API klíče pro přístup k Aliteo REST API pro interní integraci a automatizaci správy úloh.

2. **Spokojenost:**
   - Pravděpodobně spokojený – uživatel poděkoval za jasné vysvětlení situace a potvrdil svůj plán.

3. **Klíčové kroky provedené během řešení:**
   - uživatel zaslal detailní žádost o API klíč s cílem pro čtení dat.
   - technický pracovník objasnil, že API klíč s plným přístupem není aktuálně k dispozici.
   - bylo navrženo využití MCP serveru, který bude dostupný v příští verzi.
   - uživatelovi bylo poskytnuto vysvětlení o možnostech automatizace pomocí AI v rámci Aliteo.

4. **Poznámky:**
   - Řešení trvalo 2 dny.
   - Bylo přidáno celkem 17 komentářů.
   - Udržovaná dobrá komunikace mezi uživatelským a technickým pracovníkem.
   - Uživatel byl schopen nastavit dočasný workaround pomocí emailového synchronizace.
   - Komunikace probíhala jak písemně, tak i přímo v ticketu.

5. **Doporučení pro vývoj/support:**
   - zvážit vyvinutí read-only API přístupu pro uživatele s omezenými právy.
   - informovat uživatele o vydání MCP serveru a jeho funkcích včas.
   - zlepšit dokumentaci k dostupným API klíčům a jejich limitům.
