### Shrnutí support ticketu

1. **Téma ticketu:**
   - Uživatel upozornil na možné zranitelnosti v API ALITEO, které akceptuje HTML kód v komentářích navzdory označení jako "Text comment".

2. **Spokojenost:**
   - Pravděpodobně spokojený – uživatel potvrzuje funkčnost a uzavírá ticket s poděkováním.

3. **Klíčové kroky provedené během řešení:**
   - problém byl předán vývojovému týmu k dalšímu vyšetření.
   - provedeno ověření práv uživatelů API a zhodnocení rizik.
   - uživatel byl pravidelně informován o postupu a výsledcích.
   - probíhala komunikace mezi uživateli k upřesnění situace kolem API.

4. **Poznámky:**
   - Ticket trval 192813 minut od vytvoření do uzavření.
   - Celkem bylo vyměněno 8 komentářů.
   - Komunikace probíhala ve dvou směrech mezi uživateli.
   - Uživatelé vyhodnotili rizika jako minimální a situaci řádně ohlásili.

5. **Doporučení pro vývoj/support:**
   - provést revizi dokumentace API, aby odpovídala aktuálnímu stavu.
   - zajistit informování uživatelů o změnách v API a případných rizicích.
   - vytvořit automatizované testy, které by detekovaly zranitelnosti spojené s HTML.
