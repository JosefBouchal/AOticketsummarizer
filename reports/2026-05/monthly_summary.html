V měsíci květnu 2026 se nejvíce problémy soustředily v následujících oblastech systému: - API a Integrace: Mnoho ticketů se týkalo přenosu dat přes API, což vedlo ke složitým technickým diskuzím a dotazům uživatelů. - Funkcionality ALITEO: Uživatelé měly dotazy a problémy s různými funkcionalitami, včetně Ganttova plánování a filtrování úloh. - Uživatelské Účty: Časté dotazy ohledně správy uživatelských účtů (změna e-mailu, přístup k API atd.). - Fakturace: Uživatelé často žádali o pomoc při řešení problémů s fakturací a licencemi.

Opakující se hraje se zaměřily na: - Nedostatečná dokumentace: Mnoho uživatelů se potýkalo s nejasnostmi ohledně funkcí a nastavení, které by měly být více zdokumentovány. - Komunikace a Oprávnění: Zaznamenali jsme nedorozumění ohledně nastavení oprávnění a potřebných kroků pro řešení problémů.

Negativní Reakce: - Někteří uživatelé vyjádřili frustraci nad dlouhou dobou řešení ticketů, zejména těch spojených s API.

  • Zlepšení Dokumentace: Vyžaduje se aktualizace dokumentace k API a funkcionalitám ALITEO, aby byla více srozumitelná pro uživatele.

  • Technická Podpora: Bylo by prospěšné zlepšit přístup k technické podpoře pro uživatele, minimálně při složených problémech.
